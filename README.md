##  Fitur & Implementasi

Proyek ini mencakup implementasi dasar hingga modul pendukung untuk operasi Binary Tree:

1. Inisialisasi Node & Tree: Pembentukan struktur data pohon biner.
2. Operasi Tree: 
   - Penambahan/Penghapusan node.
   - Penelusuran (Traversal): In-order, Pre-order, dan Post-order.
   - Pencarian node tertentu.
3. Antarmuka Utama (`main.py`): Menjalankan program utama untuk interaksi pengguna.

##  Cara Menjalankan Program

### Prasyarat
- Python versi `3.8` atau yang lebih baru.

### Langkah-langkah
1. Clone atau Unduh Repository
   ```bash
   git clone <URL_REPOSITORY_ANDA>
   cd Kelompok_Binarytree
   ```

2. Jalankan Program Utama
   ```bash
   python main.py
   ```
   atau jika menggunakan Python 3 secara spesifik:
   ```bash
   python3 main.py
   ```
